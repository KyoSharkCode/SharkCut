Primera versión de acceso anticipado de SharkCut.

### Incluye
- Línea de tiempo con varias pistas de video, audio y subtítulos; cortes, rizo, copiar y pegar.
- Decodificación y exportación por GPU (NVDEC/NVENC) con proxies para VODs largos.
- Transiciones como clips, keyframes, efectos de imagen, pantalla verde y punto de anclaje.
- Subtítulos automáticos con transcripción local (whisper.cpp).
- Biblioteca de efectos de sonido.
- Actualizaciones automáticas: SharkCut avisa cuando hay una versión nueva.

### Requisitos
- Windows 10 u 11 de 64 bits. Se recomienda una tarjeta NVIDIA (RTX 20 o posterior).
