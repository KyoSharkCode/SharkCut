SharkCut

Política de firma del código

Última actualización: 23 de octubre de 2026

Estado

Pendiente. SharkCut va a solicitar la firma de código gratuita de SignPath.io, con certificado de SignPath Foundation. Hasta que se apruebe, las versiones publicadas no van firmadas y Windows puede mostrar un aviso al instalarlas.

Qué se firma

  • El ejecutable de SharkCut (SharkCut.exe) y el instalador (SharkCut-X.Y.Z-Setup.exe) de cada versión publicada en GitHub Releases.
  • Solo se firma lo que se compila a partir del código de este proyecto. Las bibliotecas de otros autores que van con SharkCut (Qt, FFmpeg…) se reparten tal como las publican sus autores, sin firmarlas con el certificado de SharkCut.

Cómo se compila

  • Todo lo que se firma se compila en GitHub Actions, a partir del código público del repositorio KyoSharkCode/SharkCut, con el flujo .github/workflows/build.yml. Nunca se firma nada compilado en un equipo personal.
  • Solo se firma al publicar una versión: una etiqueta vX.Y.Z en la rama principal, que debe coincidir con la versión del proyecto.
  • Cada firma la aprueba a mano una persona aprobadora antes de que se publique la versión.

Equipo y funciones

  • Autora y revisora del código: KyoSumiVT (@KyoSharkCode). Todos los cambios llegan a la rama principal mediante pull requests que ella revisa.
  • Aprobadora de las firmas: KyoSumiVT.

Las cuentas del equipo en GitHub y en SignPath deben tener activada la verificación en dos pasos.

Privacidad

SharkCut no envía información a otros sistemas salvo en lo que explica su política de privacidad: buscar actualizaciones en GitHub al abrirse (se puede desactivar) y descargar el modelo de subtítulos cuando el usuario los crea.

Avisos

Si crees que un archivo firmado con el certificado de SharkCut no viene de este proyecto o se ha usado mal, avisa en GitHub.

In English

Status: pending. SharkCut is applying for free code signing provided by SignPath.io, with a certificate by SignPath Foundation. Until it is approved, releases are not signed.

What is signed: SharkCut.exe and the installer of each release, built only by GitHub Actions from the public repository, on a vX.Y.Z tag. Third-party libraries (Qt, FFmpeg) are shipped as published by their authors and are not signed with this certificate.

Team roles: committer and reviewer: KyoSumiVT (@KyoSharkCode); approver: KyoSumiVT. Every signing request is approved manually. Team accounts must use multi-factor authentication.

Privacy: this program does not transfer information to other networked systems except as described in the privacy policy: an update check against GitHub on startup (can be turned off) and downloading the speech recognition model when the user creates subtitles.
